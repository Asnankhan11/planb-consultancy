## 1. Search Intent & Keyword Clusters Overview

Search queries in the employment and admission sectors fall into four distinct intent buckets:
1. **Transactional (High Conversion):** Candidate has resume ready and wants to apply immediately (e.g., *"apply work from home non voice jobs freshers"*).
2. **Commercial Investigation:** Candidate is evaluating legitimate opportunities or consultancies (e.g., *"genuine work from home jobs without investment maharashtra"*).
3. **Informational:** Candidate needs career or education guidance (e.g., *"career options after 12th commerce tier 2 cities"*).
4. **Navigational:** Searching specifically for Plan B Careers or founder credentials (e.g., *"plan b careers candidate verification"*, *"asnan khan plan b careers"*).

## 7. On-Page Implementation Strategy

1. **Title Tag Blueprint:**  
   `[Target Primary Keyword] | [Secondary Modifier] - Plan B Careers`  
   *Example:* `Work From Home Jobs for Freshers (Verified 2026) | Plan B Careers` (58 chars)

2. **Meta Description Blueprint:**  
   `[Hook + Primary Benefit] Discover verified [Category/Location] jobs with [Salary Range]. Apply 100% free with direct HR WhatsApp support.` (145 chars)

3. **Heading Hierarchy Rule:**  
   - Every page contains exactly **one H1** matching the primary search intent.
   - H2 tags break down key subcategories, qualifications, and benefits.
   - H3 tags structure individual job cards and specific FAQs.
   - **Zero skipped heading levels** (H1 -> H2 -> H3 strictly).

4. **Structured Schema Mapping:**  
   - Category pages -> `ItemList` + `FAQPage` + `BreadcrumbList`
   - Location pages -> `LocalBusiness` + `ItemList` + `BreadcrumbList`
   - Leaf jobs -> `JobPosting` + `BreadcrumbList`
